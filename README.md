# MyTransfer releases

Binary releases for MyTransfer. The app auto-updates from this repo.

MyTransfer allows you to transfer files/photos/documents/etc from PC/Mobile to another PC, as long as they are all in the same network.
It uses WebRtc to transfer files, so no cables needed. Also no app is needed on phone. My transfer has its own server that allows you to use it on Phone.
It is completely free and available on Mac/Windows

I know, there is AirDrop... but hey, not everyone has a mac/iPhone ;)
